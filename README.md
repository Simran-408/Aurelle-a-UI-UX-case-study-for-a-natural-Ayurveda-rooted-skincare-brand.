# Aurelle-a-UI-UX-case-study-for-a-natural-Ayurveda-rooted-skincare-brand.
Aurelle is a UI/UX case study for a natural, Ayurveda-rooted skincare brand. I designed the full flow — homepage, shop, product detail, and a 4-step personalized ritual quiz — built around one idea: making "natural" and "clinically backed" a structural part of the product, not just marketing language.
